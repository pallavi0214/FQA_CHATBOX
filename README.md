FAQ Chatbot 🤖

 About the Project

The FAQ Chatbot is a Python-based chatbot that answers frequently asked questions automatically. It uses Natural Language Processing (NLP) techniques to identify user questions and provide suitable answers.

This project was developed as part of the CodeAlpha Internship – Task 2.

 Objectives

- To provide automatic answers to frequently asked questions.

- To understand the basics of Natural Language Processing (NLP).

- To create a simple and interactive chatbot using Python.

- To improve user experience by providing quick responses.

 Tools and Technologies

- Programming Language: Python

- Libraries: NLTK, Scikit-learn

- IDE: Visual Studio Code

 Features

- Answers frequently asked questions.

- Accepts questions from users through the terminal.

- Uses text-processing techniques to understand questions.

- Provides relevant responses to user queries.


- Simple and beginner-friendly implementation.


 Installation and Execution

1. Install Python

Install Python on your computer if it is not already installed.

2. Install Required Libraries

Open the terminal and run:

python -m pip install nltk scikit-learn

3. Run the Project

Navigate to the project folder and run:

python faq_chatbot.py

4. Interact with the Chatbot

Type a question in the terminal and read the chatbot's response. Type "exit" to quit if your program supports that command.
